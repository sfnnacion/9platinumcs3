# SG4 - Understanding Classes and Objects

## Class Name
Song

## Class Description
A song is a short piece of music that includes music, lyrics, and voice. It is considered a major form of art and is created from a blend of emotion, experiences, as well as cultural traditions.

## Properties
| Property        | Data Type | Description                          |
|  title          | string    | Title of the song                    |        
|  artist         | string    | Name of the recording artist or band |
| yearReleased    |  int      | The year the song was released       |
| genre           | string    | The genre of the song                |
|durationInSeconds| int       | The length of the song in seconds    |

## Methods
|         Method            |         Description          |
| play()                    | Play the music               |
| pause()                   | Pause the song               |
| replay()                  | Replay the song              |
| fastForward(seconds: int) | Skip other parts of the song |

## Design Explanation

### Why did you choose this class?
I chose this class because I listen to songs from my favorite artists every day. Since I listen to songs a lot, it was easy for me to identify its different properties and methods or behavior. 

### Which property is the most important? Why?
The most important property is the title, because this is where you can identify what song you're listening to, making it easier to look back if ever you want to play it again.

### Which method is the most useful? Why?
The play() method is the most useful because it is the action that brings the song to life. Without it, you wouldn't be able to listen or hear the song.
